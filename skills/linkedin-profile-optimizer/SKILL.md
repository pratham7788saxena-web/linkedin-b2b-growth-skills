# LinkedIn Profile Optimizer

**Purpose:** Before anyone accepts a request or reads a post, they glance at the profile. Make that glance answer: who is this, who do they help, why trust them. Supports Stages 6–8.

Read `references/ground-rules.md` and `company-profile.md` first.

## When to use it

- Before a campaign or outreach push.
- A new role, offering or positioning.
- A founder/executive profile that doesn't reflect what the company does now.
- Company page About/tagline out of date or inconsistent with the website.

## Information to ask for

- The current profile/page text (the user pastes it, or screenshots). You read only what's provided or publicly visible.
- Whose profile it is and whether they've agreed to changes (for anyone other than the user: written OK required).
- Target audience and campaign focus.
- Whether the user is a **company page admin** (only admins can edit the page).
- The person's real work history and achievements. Never fill gaps or copy another person's history.

## Workflow

### 1. Read-only audit
Score each element 0–2 (missing / weak / strong) with a one-line reason:
- **Personal:** photo, banner, headline, About, Featured, Experience (current role has a description?), custom URL, contact info, recent activity, consistency with the company page.
- **Company page:** logo, banner, tagline, About, specialties, services listing, website link, button, recent posts, consistency with the website (e.g. team size, founding year).
Flag claims that need consent or confirmation (client logos or names, partner names, headcount, years of experience).

### 2. Prioritised fixes
Top 5 changes in order of impact for the target audience, each with why.

### 3. Drafts (ready to paste)
- **Headline** (≤ 220 chars): 3 options. Pattern: who you help + with what + proof or point of view. No buzzword stacks.
- **About** (≤ 2,600 chars, first ~250 visible): opens with the audience's problem or the person's point of view, then what they do, how, proof (approved only), and a soft CTA.
- **Experience** description for the current role (and others only from the person's real history).
- **Featured:** 3 items to pin (best post, asset, website page).
- **Banner** text (1584 × 396 personal / 1128 × 191 company): one line; design via `brand-creative-design`.
- **Custom URL** options if the preferred one is taken.
- **Company page:** tagline (≤ 120 chars), About (≤ 2,000 chars), specialties, services description, button choice.

Character limits change; tell the user to confirm in the edit screen.

### 4. Claim check and approvals
| Claim | Label | Needs consent/approval from |
List what the profile owner and company approvers must confirm before saving.

## Platform facts worth checking (they change)

- Specialties and the custom button ("Contact us", "Visit website") are **company page** features; personal profiles have neither specialties nor that button.
- Some personal-profile features (e.g. a custom button) depend on Premium. Check the account's current plan.
- Only page admins can edit a company page. Ask an existing admin to add the user if needed.

## Output format

```
# Profile Revamp — [Name / Company] — [date]
## Audit (table: element · score · note)
## Top 5 fixes
## Drafts (headline ×3, About, Experience, Featured, banner line, URL, company page fields)
## Claim check
## Approval checklist (who, what, status)
## Record this
## Next step
```

## Quality checks

- Every draft uses the person's real history and verified company facts.
- No client/partner names published without recorded consent.
- Headline and About speak to the target audience, not to recruiters (unless that's the goal).
- Text inside LinkedIn's limits; formatted plainly (avoid fake-bold Unicode, which hurts accessibility and search).

## Common mistakes to avoid

- Copying one person's work history into another's profile.
- "Passionate | Visionary | Innovator" headlines.
- Inconsistent numbers between the website, company page and founder profile.
- Editing someone's profile without their written OK.
